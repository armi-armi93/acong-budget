아콩이네 공동가계부🫛 version 3.0

성격
- 매일 소비를 기록하는 가계부가 아니라 월 1회 공동자산을 정산하는 앱
- 필요할 때만 비상금/목적자금 등의 자산사용을 별도로 기록

탭
- 홈: 현재 순자산, 이번 달 수입/생활비/저축/자산사용, 현재 재산
- 월급분배: 태환/아름/기타 수입 → 생활비성 지출 + 저축·적립
- 재산: 공동생활비 통장/카드 미결제금 없이 실제 보유재산만 관리
- 자산사용: 비상금 등에서 실제 사용한 돈을 그때그때 차감
- 기록: 월별 수입·생활비·저축·자산사용·월말 순자산 기록
- 설정: 카테고리, JSON 백업/복원, CSV 내보내기, 전체 초기화

기능
- 전월 월급분배 불러오기
- 월급분배 저장 시 저축·적립 금액을 해당 재산에 자동 반영
- 같은 달 분배 수정 시 기존 적립분을 되돌리고 새 금액 재반영
- 자산사용 수정 시 기존 차감분 복구 후 새 값 반영
- 구버전 localStorage(akong_joint_v1)의 재산을 자동 변환
- 공동생활비 통장/공동카드는 변환 시 제외
