아콩이네 공동가계부🫛 version 1

1. index.html / manifest.webmanifest / sw.js 세 파일을 같은 폴더에 업로드하세요.
2. GitHub Pages, Netlify 등 정적 웹호스팅에서 바로 사용할 수 있습니다.
3. 데이터는 브라우저 localStorage에 저장됩니다.
4. 설정 > 백업(JSON)으로 정기 백업을 권장합니다.

주요 기능
- 월 예산 / 수입 / 지출 / 남은 예산
- 공동 순자산 = 자산 - 부채
- 수입 / 지출 / 자산이동 / 부채상환
- 계좌·카드와 거래 자동 연결
- 카드 미결제금 부채 관리
- 달력 / 카테고리 분석 / 최근 6개월 분석
- 검색 / 카테고리 필터
- 거래 수정
- JSON 백업/복원, CSV 내보내기
- PWA 기본 지원
